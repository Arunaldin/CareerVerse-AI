1. Object-Oriented Programming (OOP)

Core Pillars: Encapsulation, Abstraction, Inheritance, and Polymorphism.

Common Question: What is the difference between Method Overloading and Method Overriding?
Overloading happens at compile-time with identical names but different signatures. Overriding happens at runtime when a subclass provides a specific implementation of a parent class method.

2. Database Management Systems (DBMS)

ACID Properties: Atomicity, Consistency, Isolation, Durability.

Common Question: What is the difference between Primary Key, Unique Key, and Foreign Key?
Primary Key uniquely identifies a record and cannot be NULL. Unique Key allows one NULL. Foreign Key enforces referential integrity by pointing to a Primary Key in another table.

3. Operating Systems & Networks

Topics: Process vs Thread, Paging, Virtual Memory, Deadlock conditions, and TCP 3-way handshake.

Common Question: What happens when you type a URL in the browser and press Enter?
DNS lookup -> TCP connection -> HTTP/S request sent -> Server processes and returns response -> Browser parses HTML/CSS/JS and renders DOM.
